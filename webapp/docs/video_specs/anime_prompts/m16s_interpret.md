## 一、一键复制给视频 LLM 的主 Prompt

```
请为「EasyMultiProfiler 生信课程微课」制作一段 **约 4 分钟** 的 **日系科普动漫** 教学视频。

### 课程信息
- **模块 ID**：m16s_interpret
- **标题**：16S 微生物组 · 第5步：差异菌属与可验证假设
- **组学赛道**：16S 微生物组
- **教学环节**：结果解读
- **学习目标**：理解 FDR 多重检验校正与效应量，能把差异菌属结果表述为可检验假设而非因果断言。
- **输出文件名**：videos/m16s_interpret.mp4

### 内容梗概（本集要讲什么）
讲清差异丰度分析的多重检验问题、效应量的意义，以及如何从关联走向可验证的机制假设。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:40**
上千个 taxa 同时检验的网格动画，随机点亮约 5% → 引出假阳性。

**第 2 幕 0:40–1:50**
Benjamini-Hochberg 排序校正动画：原始 p → 调整后 q 值。

**第 3 幕 1:50–2:40**
对比两个 taxa：q 值都显著，但效应量（log2FC/LDA）差别大。

**第 4 幕 2:40–3:30**
措辞对比卡：『导致疾病』❌ vs 『相关/候选，待验证』✅。

**第 5 幕 3:30–4:00**
把结果写成可验证假设 + 局限性清单。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
走到最后一步，我们要回答最有吸引力的问题：哪些菌在两组之间不一样，它们意味着什么。这里有两个必须迈过的坎。

第一个坎是多重检验。一次差异分析可能同时检验成百上千个 taxa，如果只看原始 p 值小于 0.05，纯靠运气就会有大量假阳性——检验一千个，期望就有约五十个『碰巧显著』。所以微生物组差异分析必须做多重检验校正，最常用的是 Benjamini-Hochberg 方法，得到的 FDR 或 q 值才是你判断显著的依据。报告时请用校正后的值，并写清阈值。

第二个坎是只看显著、不看效应量。一个 taxon 的 q 值很小，只说明差异稳定，不代表差异大。要结合效应量，比如 log2 倍数变化或 LDA score，来判断这个差异在生物学上值不值得关注。

最关键的是结论的措辞。你发现某菌属在病例组富集，正确的表述是『该菌属与该表型相关，是一个候选』，而不是『该菌属导致了疾病』。从关联到因果，中间还隔着混杂控制、纵向数据、以及功能验证实验。一个好的结尾，应该把发现写成一个清晰、可被后续实验证伪的假设，并坦诚列出局限性。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 差异丰度必须做多重检验校正，报告 FDR/q 值与阈值
2. 显著看 q 值，重要看效应量（log2FC/LDA），两者都要
3. 结论写成可证伪的关联假设，不下因果断言

### 质量检查清单
- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。
```

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
