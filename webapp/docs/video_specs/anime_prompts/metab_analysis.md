**第 3 幕 1:50–3:00**

**第 4 幕 3:00–3:40**
VIP 值挑重要变量 + 单变量检验配合。

**第 5 幕 3:40–4:00**
字幕：多元找方向，单变量定证据。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
代谢组是典型的高维数据——变量常常远多于样本，所以分析的主力是多元统计。这里要分清两类方法，它们的目的完全不同。

第一类是无监督的 PCA。它不看你的分组标签，只是寻找数据中方差最大的方向，把高维数据压成几张二维图。PCA 最重要的用途其实是质控：看 QC 样本是否聚在中间、有没有离群样本、有没有明显的批次结构。因为它不偏不倚，PCA 上看到的组间分离是相对可信的。

第二类是有监督的 PLS-DA 或 OPLS-DA。它知道分组标签，会主动寻找最能区分组别的方向，所以分得往往比 PCA 更开、更漂亮。但这正是危险所在：有监督方法非常容易过拟合，哪怕给它随机标签，它也能把组分开。因此用 PLS-DA 必须做严格的交叉验证，并看 R2/Q2、做置换检验，确认模型不是在『记答案』。

多元分析告诉你整体结构和重要变量（比如看 VIP 值），但要确认单个代谢物是否真的有组间差异，还要配合单变量分析：对每个代谢物做检验，并像前面讲的那样做多重检验校正。多元找方向、单变量定证据，两者互补，结论才稳。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. PCA 无监督，最适合 QC 与离群/批次检查
2. PLS-DA 有监督、易过拟合，必须交叉验证与置换检验
3. 多元分析配合单变量检验（含多重校正）才稳

- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
