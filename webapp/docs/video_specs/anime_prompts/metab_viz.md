## 一、一键复制给视频 LLM 的主 Prompt

```
请为「EasyMultiProfiler 生信课程微课」制作一段 **约 4 分钟** 的 **日系科普动漫** 教学视频。

### 课程信息
- **模块 ID**：metab_viz
- **标题**：代谢组 · 第4步：热图、火山图与得分图怎么读
- **组学赛道**：代谢组
- **教学环节**：可视化
- **学习目标**：能正确解读代谢组热图、火山图与得分/载荷图，理解可视化与前序标度化的关系。
- **输出文件名**：videos/metab_viz.mp4

### 内容梗概（本集要讲什么）
讲清代谢组热图的标度化前提、火山图阈值，以及 PLS-DA 得分图与载荷图的配合解读。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:40**
代谢物强度跨数量级 → 必须标度化后再画热图。

**第 2 幕 0:40–1:40**
热图 + 行 z-score + 聚类；字幕：模式相似≠同通路≠因果。

**第 3 幕 1:40–2:30**
火山图锁定差异代谢物，阈值事先定。

**第 4 幕 2:30–3:30**
得分图（样本分离）与载荷图（驱动变量）对照动画。

**第 5 幕 3:30–4:00**
读图三段式：描述→含义→关联非结论。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
代谢组的结果可视化，和转录组有相通之处，但有几个代谢组特有的注意点。

先说热图。代谢物之间强度差异极大，所以热图几乎一定要在标度化之后再画，通常按行做 z-score，让你看的是每个代谢物的相对高低模式，而不是被几个高丰度代谢物染成一片。热图配合行列聚类，能看出哪些代谢物在某组里协同升高或降低——但同样记住，聚到一起只代表模式相似，不代表它们在同一条代谢通路里，更不代表因果。

再说火山图。横轴是 log2 倍数变化，纵轴是校正后显著性，用来快速锁定既显著又变化大的差异代谢物。和转录组一样，阈值要事先定好。

代谢组还常看得分图和载荷图这一对。得分图展示样本在主成分或潜变量上的分布，看组间是否分离；载荷图则告诉你『是哪些代谢物在驱动这种分离』。把两张图对照着看，你才能从『组分开了』走到『因为这些代谢物分开的』。

读图的纪律不变：先客观描述图上的模式，再给出谨慎的生物学含义，并始终把它定位成关联与候选，而不是已被证明的结论。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 代谢组热图须先标度化（按行 z-score）再看相对模式
2. 得分图看样本分离，载荷图看驱动分离的代谢物
3. 可视化呈现关联/候选，不等于已证实的结论

### 质量检查清单
- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。
```

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
