### 内容梗概（本集要讲什么）
讲清差异表达模型的设计矩阵、离散度估计与 log2FC/padj 的来源，以及独立过滤的作用。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:40**
两组样本 → 字幕『哪些基因不一样？』

**第 2 幕 0:40–1:40**
设计矩阵动画：分组 + 协变量（性别/批次）。

**第 3 幕 1:40–2:40**
离散度收缩估计示意：借全体基因稳住单基因方差。

**第 4 幕 2:40–3:30**
输出三件套：log2FC / p / padj，高亮『看 padj』。

**第 5 幕 3:30–4:00**
阈值设定卡：padj<0.05 + 合理 log2FC，写清理由。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
现在进入 RNA-seq 的核心：找出在两组之间表达不同的基因。表面上是『比一比』，背后其实是一套统计建模。

第一步是定义设计矩阵，也就是告诉模型你要比什么。最简单的是『疾病 vs 对照』，但你也可以加入协变量，比如性别、批次，让模型在控制这些因素的前提下估计分组效应。把对比定清楚，是结果可信的前提。

第二步，模型要估计每个基因的『离散度』——同一条件下重复样本间的波动有多大。RNA-seq 的 count 服从负二项分布，低表达基因波动天生更大。DESeq2、edgeR 会借用全体基因的信息，对单个基因的离散度做收缩估计，这样在样本量不大时也更稳健。

第三步，对每个基因做检验，输出三样东西：log2 倍数变化（log2FC），表示效应方向和大小；原始 p 值；以及最重要的、经过多重检验校正的 padj（也就是 FDR）。判断显著要看 padj，而不是原始 p。

设定阈值时，padj 常用 0.05，log2FC 阈值要结合领域惯例和生物学意义，而不是越大越好。把方法、对比、阈值都写清楚，你的差异基因列表才站得住脚。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 设计矩阵决定『比什么』，可纳入协变量控制混杂
2. count 服从负二项分布，离散度需收缩估计才稳健
3. 判断显著看 padj（FDR），阈值要结合生物学意义

### 质量检查清单
- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
