```
### 内容梗概（本集要讲什么）
讲清鸟枪法宏基因组与 16S 的区别、物种谱(taxonomic)与功能谱(functional)表的由来与导入检查。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:50**
对比动画：16S 只测一段基因 vs 鸟枪法测全部 DNA。

**第 2 幕 0:50–1:50**
reads → MetaPhlAn/Kraken2（物种谱）+ HUMAnN（功能谱）两条产出。

**第 3 幕 1:50–2:50**
并排展示物种谱表与功能谱表的结构。

**第 4 幕 2:50–3:40**
导入检查：谱类型/方向/ID 对齐；提醒仍是组成型数据。

**第 5 幕 3:40–4:00**
字幕：先分清『谁在这』vs『能做什么』。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
宏基因组分析的第一步，是理解它和 16S 的根本区别，因为这决定了你拿到的是什么表。

16S 只扩增一段标记基因，回答『谁在这里』；鸟枪法宏基因组则不挑基因，直接打碎并测序样本里的全部 DNA。这意味着它不仅能更精细地告诉你物种组成（常到种甚至株水平），还能告诉你『这些微生物有能力做什么』——也就是功能潜力。代价是数据量大、分析更复杂、成本更高。

经过 MetaPhlAn、Kraken2 这类工具的物种分类，以及 HUMAnN 这类工具的功能注释，原始 reads 会被汇成两类谱表。一类是物种谱：行是物种（或各分类层级），列是样本，值是相对丰度。另一类是功能谱：行是基因家族、KO、或代谢通路，列是样本，值是功能丰度。EMP 里你通常会把这些谱表当作丰度矩阵导入。

导入前的检查和前面一致但更要细致：确认是物种谱还是功能谱、行列方向、样本 ID 与 metadata 对齐；同时注意这些谱表往往也是相对丰度，仍然是组成型数据，下一步预处理要按组成型对待。先分清你导入的是『谁在这』还是『它们能做什么』，后面的分析逻辑才不会混。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 鸟枪法测全部 DNA，能给出物种谱与功能谱两类表
2. 宏基因组比 16S 分辨率更高、还能看功能潜力
3. 谱表多为相对丰度，仍是组成型数据，导入需核对类型与对齐

### 质量检查清单
- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。
```

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
