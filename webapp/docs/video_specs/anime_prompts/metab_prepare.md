```
请为「EasyMultiProfiler 生信课程微课」制作一段 **约 4 分钟** 的 **日系科普动漫** 教学视频。

### 课程信息
- **模块 ID**：metab_prepare
- **标题**：代谢组 · 第2步：缺失值、归一化与标度化
- **组学赛道**：代谢组
- **教学环节**：质控与预处理
- **学习目标**：理解代谢组缺失值处理、归一化与标度化的区别与顺序，能为数据选择并说明合理的预处理策略。
- **输出文件名**：videos/metab_prepare.mp4

### 内容梗概（本集要讲什么）
讲清代谢组缺失值填补、样本间归一化与变量标度化（如 Pareto/自标度）的逻辑与顺序。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:30**
三个台阶字幕：缺失 → 归一化 → 标度化。

**第 2 幕 0:30–1:30**
缺失类型动画：组内普遍缺失（检测限）vs 随机缺失（KNN）。

**第 3 幕 1:30–2:20**
样本间归一化：总强度/内标/PQN 拉平样本。

**第 4 幕 2:20–3:30**
标度化动画：高丰度代谢物本来主导 → Pareto/自标度后低丰度显现。

**第 5 幕 3:30–4:00**
顺序流程条 + 字幕『每步记录理由』。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
代谢组的预处理，是整个分析里最容易『一步错、步步错』的环节，因为它有三件性质不同的事要做，顺序也有讲究。

第一件是缺失值。代谢组里缺失很常见，要先判断类型：如果一个代谢物在某组里普遍缺失，很可能是真的低于检测限，简单填很小的值或半个最小值是合理的；如果是随机零星缺失，则更适合用 KNN 等方法填补。无论哪种，都要记录策略与理由，绝不能一律填 0 而不说明。

第二件是样本间归一化，目的是消除样本总量或上样量的差异，让样本之间可比，常见做法包括按总峰强度归一、按内标归一，或 PQN。

第三件是变量标度化，这是代谢组特有的关键步骤。不同代谢物的强度可能相差几个数量级，如果不处理，几个高丰度代谢物会主导后续的 PCA 或 PLS-DA。Pareto 标度、自标度（unit variance）等方法把每个变量的尺度拉到可比范围，让低丰度但有信息的代谢物也能被看见。

顺序通常是：先处理缺失，再做样本归一化，最后做变量标度化与（必要时）对数变换。每一步都要能讲出为什么，这样你的多元分析才不会被技术伪差带偏。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 缺失值要分类型处理（检测限 vs 随机），不可一律填 0
2. 样本间归一化消除上样/总量差异，使样本可比
3. 变量标度化（Pareto/自标度）避免高丰度代谢物主导多元分析

### 质量检查清单
- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。
```

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
