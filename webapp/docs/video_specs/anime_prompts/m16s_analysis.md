### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
微生物组分析的核心问题之一是：这些群落『有多丰富、有多不同』。这就引出两个来自生态学的概念——Alpha 多样性和 Beta 多样性。

Alpha 多样性描述的是『一个样本内部』的多样性，回答『这个群落里有多少种、分布得均不均匀』。最常用的是 Shannon 指数，它同时考虑了丰富度（有多少种）和均匀度（各种之间是否平均）；Simpson 指数则更强调优势种。Observed/Chao1 偏重纯粹的物种数。当你比较两组的 Alpha 多样性时，记住一个前提：测序深度要可比，否则深度高的样本天然多样性更高，比较就不公平——这正是上一步要抽平或校正的原因。

Beta 多样性描述的是『样本之间』的差异，回答『两个群落结构有多不一样』。它先用一个距离或不相似度指标量化样本两两之间的差距，比如 Bray-Curtis（看丰度差异）、Jaccard（只看有无）、或带系统发育信息的 UniFrac。然后通常配合 PERMANOVA 这类检验，判断组间差异是否显著。

在 EMP 里，你会在 Analyze 页运行这些指数。做完别忘了一件事：统计显著只说明『差异不太可能是偶然』，它本身不等于因果，也不等于差异在生物学上重要。要结合效应量和实验设计一起看。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. Alpha 是样本内多样性（Shannon=丰富度+均匀度）
2. Beta 是样本间差异，靠距离矩阵 + PERMANOVA 检验
3. 比较 Alpha 前必须保证测序深度可比；显著不等于因果

- **画幅**：16:9，1920×1080，24fps

- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
