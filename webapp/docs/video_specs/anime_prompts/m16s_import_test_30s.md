## 一、直接复制给视频 LLM 的 Prompt（30 秒）

```
请制作一段 **30 秒** 的 **日系科普动漫** 教学短片，用于测试「EasyMultiProfiler 生信课程」的视觉风格与内容表达。

### 基础信息
- **主题**：16S 微生物组数据导入 — 我们拿到的是一张「丰度表」
- **时长**：30 秒（±2 秒）
- **画幅**：16:9，1920×1080，24fps
- **语言**：中文普通话旁白 + 简体中文硬字幕
- **风格**：2D 赛璐璐科普动漫，参考《工作细胞》科普感 + 3Blue1Brown 抽象图解
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键结构用高饱和荧光色

### 角色设定（必须保持一致）
- **小研**：东亚女性研究生，25 岁，深棕马尾，圆框眼镜，白大褂内搭浅蓝衬衫，在 EMP 界面操作
- **博导酱**：温和中年男性导师，短发，深蓝西装，负责讲解概念
- **菌菌**：半透明蓝绿细菌精灵，头顶分类标签（门/纲/属），用于表现微生物

### 分镜脚本（共 4 幕，严格按时长）

**第 1 幕：开场（0:00–0:06，6 秒）**
- 画面：星空推进 → 实验室全景 → 小研坐在电脑前，菌菌在她肩上探头
- 旁白：「16S 微生物组分析的第一步，是搞懂我们手里的数据到底是什么。」
- 字幕：16S 微生物组 · 数据导入
- 镜头：推轨 Zoom-in，从宇宙到实验室桌面

**第 2 幕：从样本到 reads（0:06–0:13，7 秒）**
- 画面：一管粪便/拭子样本 → 通用引物环绕 DNA 片段 → 测序仪发光 → 飞出大量 reads（细长光粒子）
- 旁白：「从样本里扩增 16S 基因，测序后得到大量短序列，叫做 reads。」
- 字幕：样本 → 测序 → reads
- 镜头：环绕 + 粒子流，菌菌沿 reads 飞舞

**第 3 幕：从 reads 到丰度表（0:13–0:22，9 秒）**
- 画面：reads 聚合成 ASV/OTU 小簇 → 分类标签（门/纲/属）逐个亮起 → 溶解汇聚成一张矩阵
- 矩阵高亮：行=taxa（菌菌一行），列=样本，格子数字跳动
- 旁白：「reads 聚成分类单元，最终变成一张『taxa × 样本』的丰度表。」
- 字幕：行 = taxa，列 = 样本
- 镜头：从分子群推进到数据矩阵，粒子溶解过渡

**第 4 幕：对齐 metadata + 收尾（0:22–0:30，8 秒）**
- 画面：丰度表右侧出现 metadata 表，两表用发光线条按「样本 ID」连接，对上的行亮起绿色，对不上的行闪烁红色
- 右下角画中画（≤25%）：小研在 EMP 界面点击「Import」，高亮对齐检查步骤
- 旁白：「导入前一定要核对样本 ID 一致，否则后续分析全错。」
- 字幕：metadata 通过样本 ID 对齐
- 收尾：最后 1 秒定格 takeaway 字幕卡：「导入先对 ID」
- 镜头：分屏 + 画中画，最后淡入字幕卡

### 视觉要求
- 禁止白底 PPT、静态 bullet 列表、无实体的纯几何图标
- 每 8 秒必须有镜头运动或新元素入场
- 数据图表从生物学实体「粒子溶解」出现，而非硬切
- 字幕关键词用黄色描边高亮：「丰度表」「taxa」「样本 ID」
- 旁白先声后画，语速 180–200 字/分钟

### 输出要求
- 30 秒 MP4，H.264 + AAC
- 文件名：m16s_import_test_30s.mp4
- 请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式
```
