- **输出文件名**：videos/rnaseq_prepare.mp4

### 内容梗概（本集要讲什么）
讲清文库大小差异、DESeq2 中位数比值归一化的思想，以及低表达基因过滤的作用。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:40**
两个样本总 reads 不同的示意 → 直接比较被打叉。

**第 2 幕 0:40–2:00**
中位数比值法动画：几何平均参考 → 比值 → 取中位数 size factor。

**第 3 幕 2:00–2:50**
强调归一化在 DESeq2 内部完成，故需原始 count。

**第 4 幕 2:50–3:30**
低表达基因接近 0 → 被过滤，检验功效提升。

**第 5 幕 3:30–4:00**
批次效应示意 + 字幕：设计平衡 + 模型校正。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
拿到 count 矩阵后，不能直接横向比较两个样本的原始计数，因为它们的『文库大小』通常不一样——也就是总 reads 数不同。一个样本某基因 count 高，可能只是因为它整体测得更深，而不是真的表达更高。归一化就是为了消除这种系统性差异。

DESeq2 用的是一种很巧妙的『中位数比值法』。它的直觉是：大多数基因在不同样本间其实变化不大，可以当作内部参照。算法对每个基因取跨样本的几何平均作为参考，再看每个样本相对参考的比值，取这些比值的中位数作为该样本的缩放因子 size factor。用中位数而不是总和，好处是几个超高表达基因不会绑架整体归一化。注意，这个归一化是 DESeq2 在内部完成的，这也是为什么它要原始 count。

另一件该做的事是过滤低表达基因：在几乎所有样本里都接近 0 的基因，既提供不了信息，又增加多重检验负担，独立过滤掉它们能提升检验功效。

最后提醒批次效应：如果样本来自不同测序日期或平台，差异可能被技术因素污染。理想做法是在设计阶段就平衡批次，并在模型里把批次当协变量。预处理做扎实，差异分析才不会被技术噪声带偏。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 文库大小不同导致 count 不可直接比较，需归一化
2. DESeq2 用中位数比值法估计 size factor，需原始 count
3. 过滤低表达基因提升功效；批次效应要在设计与模型中处理

- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
