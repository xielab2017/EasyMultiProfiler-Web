### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
欢迎来到 16S 微生物组分析的第一步——数据导入。在动手之前，先要彻底想明白：我们手里的数据到底是什么、从哪来。

16S rRNA 基因是几乎所有细菌都携带的一段保守基因，中间夹着若干高变区。我们用通用引物把这段基因扩增、测序，再通过 DADA2 或 QIIME2 这样的流程把原始 reads 聚成 ASV 或 OTU，并比对数据库得到分类注释。所以你最终拿到的，不是序列本身，而是一张「丰度表」：行通常是分类单元（taxa，比如某个属或某个 ASV），列是样本，格子里的数字是该 taxon 在该样本里的计数或相对丰度。

第二份关键文件是 metadata，也就是样本信息表。它的每一行对应一个样本，列是分组、表型、采样时间、测序批次等变量。导入 EMP 时，软件要把丰度表和 metadata 按「样本 ID」拼起来，所以这一步最容易出错的地方就是：两张表的样本 ID 写法不一致、数量对不上、或者顺序被打乱。

因此导入前请务必检查三件事：第一，丰度表是不是 taxa 在行、样本在列；第二，样本 ID 在两张表里是否一字不差地能对上；第三，分组变量在 metadata 里是否有缺失。导入后，立刻打开 Inspector，核对样本数、分组分布和 taxa 数量是否符合预期。只有数据「站对了位置」，后面所有分析才有意义。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 16S 的产物是『taxa × 样本』丰度表，不是原始序列
2. metadata 通过样本 ID 与丰度表对齐，ID 必须完全一致
3. 导入后第一件事是用 Inspector 核对样本数与分组分布

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
