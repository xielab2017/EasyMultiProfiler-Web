## 一、一键复制给视频 LLM 的主 Prompt

```
请为「EasyMultiProfiler 生信课程微课」制作一段 **约 4 分钟** 的 **日系科普动漫** 教学视频。

### 课程信息
- **模块 ID**：metab_interpret
- **标题**：代谢组 · 第5步：通路、关联与因果的边界
- **组学赛道**：代谢组
- **教学环节**：结果解读
- **学习目标**：理解相关不等于因果、混杂与反向因果，能把代谢组关联结果写成可验证的机制假设并声明 AI 使用。
- **输出文件名**：videos/metab_interpret.mp4

### 内容梗概（本集要讲什么）
讲清代谢通路富集的解读、相关性不等于因果、混杂与反向因果，以及如何提出可验证机制假设。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:40**
差异代谢物 → 通路图；字幕『统计富集≠通路被激活』。

**第 2 幕 0:40–2:10**
相关散点图 → 展开四种解释：因果/反向/混杂/巧合。

**第 3 幕 2:10–3:00**
把发现改写成可证伪的机制假设卡片。

**第 4 幕 3:00–3:40**
下一步验证：动物/细胞/干预/纵向队列。

**第 5 幕 3:40–4:00**
AI 使用声明字幕。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
代谢组分析的最后一步，是把差异代谢物变成有意义、且经得起推敲的科学解读。这里最大的陷阱，就是把相关当成因果。

先说通路解读。你可以把差异代谢物映射到代谢通路，做通路富集，看哪些通路被显著富集。但和基因富集一样，这是集合层面的统计富集，提示『这些代谢物扎堆在某通路』，并不证明该通路被激活或导致了表型。

更要警惕的是关联到因果的跳跃。假设你发现某代谢物水平与疾病强相关，这至少有四种可能：是它影响了疾病（你想要的因果）；是疾病改变了它（反向因果）；是第三个因素，比如饮食、用药、年龄，同时影响了两者（混杂）；甚至只是巧合。一张漂亮的相关散点图，区分不了这四种情况。

所以正确的科学姿态是：把发现表述成一个清晰的、可被实验证伪的机制假设，比如『菌群产生的某代谢物可能通过某受体影响宿主表型』，然后明确列出局限性，并设计下一步验证——动物或细胞功能实验、干预实验、或纵向队列。如果你用 AI 辅助生成了解读或假设，务必逐句人工批判性修改，并在报告中声明哪些部分由 AI 协助完成。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 通路富集是集合层面统计富集，不等于通路被激活
2. 相关可能源于因果、反向因果、混杂或巧合，需区分
3. 把发现写成可证伪假设并设计验证实验，声明 AI 使用

### 质量检查清单
- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。
```

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
