```
请为「EasyMultiProfiler 生信课程微课」制作一段 **约 4 分钟** 的 **日系科普动漫** 教学视频。

### 课程信息
- **模块 ID**：metab_import
- **标题**：代谢组 · 第1步：代谢组数据是什么、导入什么
- **组学赛道**：代谢组
- **教学环节**：数据导入
- **学习目标**：理解代谢组特征表的由来与结构，知道靶向与非靶向的区别，能在导入前核对特征、样本与缺失情况。
- **输出文件名**：videos/metab_import.mp4

### 内容梗概（本集要讲什么）
讲清代谢组（靶向/非靶向、LC-MS/GC-MS/NMR）的数据来源、特征表结构与导入前检查。

### 视觉与角色（必须遵守）
风格：日系科普动漫，角色「小研+博导酱」，深蓝科幻背景，数据图从生物画面过渡出现。

### 分镜要求（共 5 幕，按时间顺序制作）
**第 1 幕 0:00–0:40**
小分子代谢物 + 字幕『最接近表型的一层组学』。

**第 2 幕 0:40–1:30**
三平台图标 LC-MS/GC-MS/NMR → 峰提取/对齐 → 特征表。

**第 3 幕 1:30–2:20**
特征表结构：样本×feature；提醒行列方向可能相反。

**第 4 幕 2:20–3:10**
靶向 vs 非靶向对比：窄而准 vs 广而杂。

**第 5 幕 3:10–4:00**
导入检查：方向/ID 对齐、QC 样本、缺失值概览。

### 旁白全文（请严格覆盖，可微调口语化，不可删减科学要点）
代谢组学测的是生物体内的小分子代谢物，它最贴近表型，常被称为离『性状』最近的一层组学。我们先弄清你手里的数据是怎么来的。

主流的检测平台有三类：LC-MS、GC-MS 和 NMR，其中质谱（MS）应用最广。仪器原始信号经过峰提取、对齐、定量等预处理，最终汇成一张『特征表』：行通常是样本，列是代谢特征（feature，可能是已鉴定的代谢物，也可能只是一个 m/z 加保留时间的未知峰），格子里是峰强度或浓度。注意它的行列方向可能和 16S/RNA-seq 相反，导入时要看清。

还要区分靶向和非靶向。靶向只测一组预先选定、可绝对定量的代谢物，结果干净但视野窄；非靶向尽量捕捉所有可检测的峰，覆盖广但含大量未知特征和噪声，更需要严格 QC。

导入 EMP 前请检查三件事：第一，样本和特征的方向是否正确，样本 ID 是否与 metadata 对齐；第二，是否包含 QC 样本（多次进样的质控），它们是判断数据可靠性的关键；第三，缺失值有多少——代谢组缺失很常见，可能是真的低于检测限，也可能是技术丢失，先心里有数，下一步再决定如何处理。

### 结尾 3 要点字幕卡（各停留 3 秒）
1. 代谢组数据是『样本×特征』表，行列方向需看清
2. 靶向准但窄，非靶向广但含未知峰与噪声，需严格 QC
3. 导入前确认 ID 对齐、QC 样本与缺失值情况

### 质量检查清单
- [ ] 是否用动漫角色讲解，而非 PPT？
- [ ] 是否每 8–12 秒有镜头运动或新元素？
- [ ] 数据概念是否从生物学画面「过渡」到图表？
- [ ] 是否包含 1 段 EMP 软件画中画操作？
- [ ] 结尾是否显示 3 条 takeaway？

请按分镜输出：场景编号、时长、画面描述、角色动作、台词/旁白、字幕、转场方式。
```

## 三、全局动漫风格（详见 `00_GLOBAL_ANIME_STYLE.md`）

## 全局动漫视觉设定（所有课程视频统一）

- **风格**：日系科普动漫（类似《工作细胞》科普感 + 3Blue1Brown 抽象图解），2D 赛璐璐，线条干净，非 Q 版
- **画幅**：16:9，1920×1080，24fps
- **时长**：约 4–5 分钟（240–300 秒）
- **背景**：深蓝渐变宇宙感（#060b18 → #0f1f3d），关键生物学结构用高饱和荧光色
- **固定角色**：
  - **小研**（女研究生，白大褂+马尾，负责提问与操作 EMP）
  - **博导酱**（温和男导师形象，负责讲解概念，旁白主声可对应此角色）
  - **菌菌 / 基因君 / 代谢小精灵**（拟人化分子或微生物，按章节替换）
- **镜头语言**：远景（组织/群落）→ 中景（细胞）→ 近景（数据矩阵/UI）；每 8–12 秒有一次视觉变化
- **数据可视化**：矩阵/热图/火山图从生物学实体「汇聚溶解」出现，禁止白底 PPT 翻页
- **字幕**：简体中文硬字幕，关键词高亮（黄色描边）
- **配音**：中文普通话，纪录片科普语速（180–200 字/分钟），先声后画（旁白提前 0.2s）
- **EMP 衔接**：右下角画中画（≤25%）展示 EasyMultiProfiler 界面操作，圆角 8px
- **禁止**：静态 bullet 列表、无实体的纯几何图标、与旁白无关的素材拼接、夸张表情包
