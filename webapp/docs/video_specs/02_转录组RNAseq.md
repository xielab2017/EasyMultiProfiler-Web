## 课 1 · `rnaseq_import` — count 矩阵是什么、导入什么

**输出文件**：`videos/rnaseq_import.mp4`

### 场景 1 · 从细胞到 mRNA（0:00 – 0:45）

**旁白**  
转录组测的是：在某一时刻，细胞里有哪些基因正在转录成 mRNA。  
RNA-seq 不是直接数蛋白质，而是用测序间接估计基因表达量。  
今天跟一条 mRNA 从细胞核出来，到变成你 Excel 里那一格 count 的全过程。

**主镜头**  
真核细胞剖面：核膜、核糖体、内质网。

**动画细节**  
- Pol II 沿 DNA 转录，pre-mRNA 剪接，成熟 mRNA 从核孔导出  
- mRNA 分子带 poly-A 尾，荧光标记  
- 文库构建：片段化 → 接头连接 → PCR 扩增（简化动画）

---

### 场景 2 · 比对与计数（0:45 – 1:50）

**旁白**  
测序得到短 reads，比对到参考基因组或转录组。  
比对到某个基因外显子区域的 reads 数，就是原始 count。  
行是基因，列是样本——这是 DESeq2 和 edgeR 要求的输入格式。

**动画细节**  
- 参考基因模型（外显子块 + 内含子线）  
- reads 像箭矢落入外显子，计数器 +1、+1、+1  
- 多基因并行计数，汇成矩阵  
- 未比对、多比对 reads 进入灰色回收桶（说明过滤）

**数据与标注**  
基因 `GAPDH` count=1240，`TP53` count=89

---

### 场景 3 · count vs CPM vs TPM（1:50 – 3:00）

**旁白**  
count 受测序深度和基因长度影响。  
CPM 校正深度，TPM 还校正基因长度，便于样本内比较基因。  
但差异分析必须用原始 count——统计模型会自己估计 size factor 和离散度。  
把 TPM 喂给 DESeq2，结果不可靠。

**动画细节**  
- 三列并行：同一基因在样本 A/B 的 count、CPM、TPM 变换过程  
- TPM 管道打红叉挡在 DESeq2 入口前  
- size factor 示意：样本总 count 不同 → 缩放系数

---

### 场景 4 · colData 对齐（3:00 – 4:10）

**旁白**  
colData 每行一个样本，列是分组、批次、协变量。  
行名必须等于 count 矩阵的列名。  
基因 ID 类型要一致：Ensembl、Symbol 或 Entrez，必要时转换。

**动画细节**  
- count 列头与 colData 行名连线  
- ID 转换：ENSG00000141510 → TP53（数据库图标）

**EMP 衔接**  
Import RNA-seq count + colData；Inspector 基因数、样本数

---

### 场景 5 · 收尾（4:10 – 5:00）

**旁白**  
确认：基因在行、样本在列；原始 count；colData 匹配。  
下一节讲归一化与低表达过滤。

## 课 2 · `rnaseq_prepare` — 归一化与低表达过滤

**输出文件**：`videos/rnaseq_prepare.mp4`

### 场景 1 · 文库大小（0:00 – 1:10）

**旁白**  
两样本总 reads 不同，不能直接比原始 count。  
DESeq2 用中位数比值法估计 size factor：大多数基因不变，作为参照。

**动画细节**  
- 两样本总深度柱条 40M vs 20M  
- 基因比值分布图，取中位数为缩放因子  
- 校正后 count 叠合可比较

---

### 场景 2 · 低表达过滤（1:10 – 2:20）

**旁白**  
几乎全样本接近 0 的基因，增加噪声和检验负担。  
独立过滤提升功效。

**动画细节**  
- 表达分布图，左侧低密度区被「切除」  
- 保留基因数 20000→15000

---

### 场景 3 · 批次效应（2:20 – 3:30）

**旁白**  
不同测序批次可能带来技术差异。  
设计阶段平衡批次；分析时在 design 公式中加入 batch。

**动画细节**  
- PCoA 上样本按批次着色，与分组混淆  
- design 公式 `~ batch + group` 文字飞入

---

### 场景 4 · EMP Prepare + 收尾（3:30 – 5:00）

**EMP 衔接**  
filter 低表达、查看 size factor、记录 design

## 课 3 · `rnaseq_analysis` — 差异表达分析

**输出文件**：`videos/rnaseq_analysis.mp4`

### 场景 1 · 设计矩阵（0:00 – 1:20）

**旁白**  
告诉模型要比什么：疾病 vs 对照，是否纳入性别、批次。

**动画细节**  
- 样本 × 协变量矩阵，高亮 group 列  
- 对比：`groupTreatment` vs `groupControl`

---

### 场景 2 · 负二项与离散度（1:20 – 2:40）

**旁白**  
count 服从负二项分布，低表达基因方差大。  
DESeq2 收缩离散度估计，小样本更稳。

**动画细节**  
- mean-variance 散点 → 拟合曲线  
- 单基因离散度向全局收缩

---

### 场景 3 · log2FC、p、padj（2:40 – 4:00）

**旁白**  
输出 log2 倍数变化、原始 p、校正后 padj。  
判断显著看 padj，阈值事先设定。

**动画细节**  
- 火山图构建过程逐帧  
- padj 阈值线 0.05

### 场景 4 · EMP Analyze + 收尾（4:00 – 5:00）

## 课 5 · `rnaseq_interpret` — 功能富集与解读

### 场景 1 · ORA（0:00 – 1:40）

**旁白**

### 场景 2 · GSEA（1:40 – 3:00）

**旁白**

**动画细节**  
- Running enrichment score 曲线经典动画

---
