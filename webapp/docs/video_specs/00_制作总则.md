# 00 · 制作总则（CNS / 科普动画标准）

## 1. 视觉风格定位

**参考标杆**（制作前团队应统一观看 2–3 条）：
- *Nature Reviews Microbiology* 配套动画（分子机制 + 简洁旁白）
- *Cell Press* Graphical Abstract 动态版（数据流 + 细胞背景）
- 3Blue1Brown 式「抽象→具体」过渡（数学/数据概念可视化）
- *Illumina* / *QIIME2* 官方技术动画（测序与生物信息流程）

**禁止**：
- 白底 PPT 翻页、静态 bullet 列表占满屏幕
- 无生物学实体的纯几何图标（当前 Canvas 版本的弱点）
- 与旁白不同步的通用素材拼接

**推荐**：
- 深色背景（#060b18–#0f1f3d）+ 局部体积光；关键生物学结构用高饱和色
- **三层画面**：远景（组织/群落）→ 中景（细胞/分子）→ 近景（数据矩阵/UI）
- 数据出现时从生物学实体「溶解/汇聚」为矩阵，而非硬切

## 2. 镜头与运动

| 类型 | 用法 |
|------|------|
| 推轨 Zoom-in | 从样本容器推进至细胞/分子 |
| orbit 环绕 | 展示 3D 菌群群落、PCoA 点云 |
| 粒子流 | reads、代谢物、DNA 片段沿管道流动 |
| 分屏 | 左：生物学过程；右：同步出现的数据表行/列 |
| 画中画 | 主画面动画 + 右下角 EMP 操作录屏（≤25% 画幅） |

单场景镜头切换 2–4 次为宜；每 8–12 秒应有一次视觉变化（运动、高亮或新元素入场）。

## 3. 数据可视化规范

- **热图/矩阵**：行名列名清晰；数值变化用颜色插值动画，非整表闪现
- **火山图/散点**：点逐粒落入；阈值线先于点出现（虚线），再标注显著区
- **组成堆叠条**：仅相对丰度场景必须同步显示「绝对 vs 相对」小窗对比
- **通路图**：节点为代谢物/基因，边为反应；富集时整条子网络高亮脉冲

字体：中文 PingFang SC / 思源黑体；英文 Helvetica Neue；数据标签 ≥ 18px @1080p。

## 4. 旁白与音效

- 旁白提前 0.2s 于画面关键动作（观众先听到概念，再看到图示）
- 环境音：测序仪低频嗡鸣、PCR 热循环「嘀」、数据流动「嗖」（极低音量）
- 无背景音乐或仅 5% 音量铺底，避免盖过人声

## 5. EMP 界面录屏规范

- 使用浅色主题 EMP，分辨率 1920×1080，鼠标移动平滑
- 高亮点击区域用圆形光圈，不用粗糙箭头
- 录屏片段每段 ≤ 15s，外圈加 8px 圆角与 1px 描边融入主画面

## 6. 交付物清单（每节课）

1. `模块ID.mp4`（H.264, AAC, 5min）
2. `模块ID.srt` 中文字幕
3. `模块ID_storyboard.pdf`（可选，本 MD 即分镜源）
4. 源工程文件（AE / Blender / C4D 等）
