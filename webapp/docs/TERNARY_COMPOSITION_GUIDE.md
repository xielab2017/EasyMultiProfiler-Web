# 三元组成图的使用与分析边界

三元图属于组成描述：导入丰度矩阵 → 样本 QC → 确认非负丰度与分类层级 → 核对分组 → 选择三个真实组 → 作图。它不依赖先做差异分析，不能代替差异检验。

当前应用接入微生物组和宏基因组。每个点代表一个特征。先对每个样本按全特征总量计算相对丰度，再求三个组各自的均值；将该特征的三个组均值除以三者之和，得到和为 1 的三元坐标。气泡大小为三个组均值的等权平均，不因某组样本多而增加权重。颜色表示均值最高的组，不能当作分类学颜色或显著性标记。

例如某菌的三个组均值为 0.02、0.01、0.01，顶点坐标是 50%、25%、25%；不是“该菌占第一个样本/组总体的 50%”。群落相对丰度没有测量细胞数或绝对生物量，组成关系还受其他特征影响。[Gloor et al., 2017](https://www.frontiersin.org/journals/microbiology/articles/10.3389/fmicb.2017.02224/full)

| 数据 | 适用条件 |
|---|---|
| 微生物组/宏基因组 | 非负计数或丰度，明确分类层级，经过适当 QC；相对丰度只用于描述 |
| 转录组 | 原理上可描述非负、可比较的表达组成，但不是 DESeq2/edgeR 的输入变换，也不能由位置判断差异表达；当前未开放本适配器 |
| 蛋白组/代谢组 | 原理上可描述同一特征的三组可比非负强度；先处理并报告缺失和尺度，不同分子响应因子使“组成”解释更受限；当前未开放本适配器 |
| 临床/表观数据 | 不可直接将不同单位的临床变量或任意评分相加闭合；需另行定义合理、同尺度且非负的三组量 |
| 多组学联合 | 不能把转录组、蛋白组、代谢组三个矩阵直接当作三个顶点；必须先定义可比的共同特征或明确的整合量 |

不适用 CLR/rCLR、中心化值、任意负值、log2FC、统计量和 P 值。应用不会为了作图反推原始丰度、平移负值或补造第三组。当前只有两个真实组时按钮禁用；三个以上组应明确选出三个，其他组不计入这张图。

图上组均值不体现组内变异或不确定性。若要提出组间差异结论，应另做适合数据、独立性与设计的检验，报告效应量、多重检验和生物学重复；对于配对或重复测量不能忽略受试者结构。
