Cross-Omics Integration (inter-omics)

Integrates two experiments to quantify feature-feature associations across omics layers (for example: taxa vs genes, taxa vs metabolites, genes vs metabolites). Current version provides a guided entry and recommended workflow; full automated model block (CCA/DIABLO/MOFA) will be added next.

  1. Load at least two experiments in the same session.
  2. Complete per-omics preprocessing first (filter/normalize/impute/taxonomy).
  3. Use shared sample IDs and run pairwise correlation in Clinical/Correlation modules.
Tip: for publication-grade inter-omics, ensure confounders are adjusted and report FDR.

Clinical & Phenotype Analysis

3. WGCNA module – trait correlation

Combine transcriptomics / proteomics / microbiome features with clinical variables to train single-marker and multi-marker warning models. Outputs include ROC-derived AUC, best cut-off, sensitivity, specificity, sample size, and whether AUC > 0.8.
