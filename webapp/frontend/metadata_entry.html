v9.1.3 新功能入口 / New features

论文/PDF、GEO/SRA/ENA、count matrix下载、流程搭建预检、受限AI工具接口在独立的元数据服务中。它不会随原R首页自动启动。

The metadata service is separate from the R application. Opening this page does not start it or configure an AI model.

1. 从当前开发版目录启动

  • Windows：双击 Start-EMP-Metadata.cmd
  • macOS：打开 Start-EMP-Metadata.command
  • Linux：执行 bash Start-EMP-Metadata.sh
  • 通用：python webapp/scripts/launch_metadata.py

需Python≥3.10，不需要R。PDF解析另需pypdf。终端会显示准确网址；如果端口已修改，请用终端网址。

2. 打开元数据页面

打开默认本机入口 / Open default local service

此链接只适用于在你当前电脑启动服务且未改端口的情况；若连接失败，请先启动上一步。远程服务器请使用已获批准的访问方式，不要直接公开端口。

已实现：小型处理矩阵的单独确认下载、流程预检、可选只读智能体接口。未实现或未验收：FASTQ下载执行、完整R分析衔接、多组学执行、真实模型调用。页面不接收API密钥。
