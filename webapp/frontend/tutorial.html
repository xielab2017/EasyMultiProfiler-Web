Text guide / 文字步骤

  1. Start the metadata-only launcher, then open its printed local address. 使用元数据启动器，打开终端显示的本机地址；不需要 R。
  2. Read the scope warnings. PDF extraction stays local; PubMed/GEO queries require network access. 阅读能力边界；PDF本地解析，公开文献和数据检索需要网络。
  3. Review processed matrix candidates, provenance, size and separate download confirmation. 文件名不能证明 raw counts；先核对来源、大小和注释，再确认下载。
  4. Edit the bulk RNA-seq plan and validate inputs and sample matching. A validated plan is not an executed analysis. 修改流程模块并检查样本ID、分组及数据类型；预检通过不代表分析完成。
  5. Preview the selected agent context before consenting to a configured provider. No key belongs in the page. 智能体需服务端安全配置与逐次授权；页面不收集密钥。
