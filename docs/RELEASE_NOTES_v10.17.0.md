# EasyMultiProfiler Web 10.17.0

修正降维图默认椭圆的含义，并让轴向统计直接显示在投影旁。

- 默认由组均值置信区域改为 95% 正态组内分布椭圆，适合展示组内样本散布；均值置信区域仍可明确选择。首次迁移旧默认，之后保存用户选择。椭圆不会为了包住每一个点而虚构覆盖率。
- X / Y 轴投影标题直接显示总体 P 和 BH q，替换容易遗漏的右上角集中显示。
- 新增组间两两比较，可选全部组对、参考组或关闭；括号显示原始 P、BH 校正值或两者，完整数据新增 PAIRWISE 下载。两两比较的 BH 比较族为所有请求组对 × 两条轴。
- 默认仅对有重复的已知组计算检验；单例点和图例保留，明确记录被排除的组及样本数。可选全部组并查看不足时的 NA 原因，未补造检验结果。
- 依据物理画布与字号安排标注。紧凑画布保留完整分布、总体 P 与默认展开的完整统计表，提示两两括号转入 PAIRWISE；不强制改变用户尺寸或字体。
- 结果表记录有效 N、缺失 N 和单例排除 N，均值 / 分布椭圆、统计范围与标注数量进入清单。所有操作读取保存坐标，源数据和降维模型不变。

验收：176 项 Node 测试；真实 R 核对 Wilcoxon / Welch 两两原始 P、跨轴 BH、参考组、无效数据和单例排除；真实浏览器检查默认分布椭圆、总体 P、两两比较、范围切换、下载、自动 / 手动参数与窄屏。PDF 物理尺寸与矢量对象、源坐标和完整统计通过核对。

使用和统计定义见 [降维图说明](ORDINATION_GROUP_FIGURES.md)。

本机上线复验：网页、R API 与实际加载 R 包一致为 10.17.0，MiniMax 仍为 ready。截图对应的保存 PCoA / Group 结果保持 132 个原始坐标，默认分布椭圆分别按 IBS_before（71）和 UC_before（60）估计；IBS_after（1）保留为点并明确不参与默认检验。131 个样本的独立复算得到 PCoA1 P=0.9649956、PCoA2 P=8.765567e-7，跨轴 BH 校正与两两比较表一致。实际 180 × 160 mm PDF 保留矢量对象，总体 P 与括号标注明确，源文件校验值不变。真实 8080 浏览器同时验证旧默认迁移、参考组选项、完整统计表和不重新运行降维。
