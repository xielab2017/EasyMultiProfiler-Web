# EasyMultiProfiler Web v9.4.0

2026-11-18 · 本地发行版

## AI 对话与扩展

网页可导入 Zotero 的模型配置，在问答和 Agent 两种模式下生成回答、摘要、比较或笔记。修复了配置切换后旧请求写回验证状态，以及多附件截断后回执字数不准确的问题。[对话说明](ZOTERO_CHAT.md)

外部 AI 服务可通过独立目录注册模型提供方。MiniMax 继续使用内置配置，Groq 是第三方插件清单示例。模型插件契约和对话协议分别维护版本号。[插件开发说明](../plugins/ai-providers/README.md)

## 分析修复

| 模块 | 本版行为 |
| --- | --- |
| 转录组 | 修正旧版 edgeR 两组比较方向，保留 DESeq2 独立过滤的缺失 FDR。特征相关性筛查按所选 Pearson 或 Spearman 方法及绝对相关阈值返回结果。 |
| 16S | 修正 observed 丰富度、分类层级解析和计数整数溢出的处理。 |
| 多组学整合 | 入队前校验分组和缺失值策略。命令行支持含空格的路径，导出保留数值精度。 |
| 临床 | 按基线访视统计，配对时检查同一受试者的重复访视。 |
| ChIP-seq | 校验 BED 区间并修正峰顶窗口宽度。本机验收覆盖已有峰表的 QC、交并、排序和出图。 |

## 后台作业与容量

默认最多同时运行 4 个 R 工作进程，另有 16 个等待位。已取消或失败的计数计划可以重试。相同的运行中或成功计划复用原作业。工作进程将大结果预先序列化，读取遇到缺失或截断时从 RDS 恢复。

在本机隔离压测中，12 个客户端各提交一份 4,000 基因 × 6 样本的合成计数矩阵，12 项均完成。总耗时 20.22 秒，68 次健康检查全部成功，P95 为 24 毫秒。该轮测量的是 R 分析服务。AI 输出协议另用本地受控模型验证。

既有项目、会话和已完成作业沿用原存储目录。重启会释放 Python 临时工作台记录及服务端模型连接，当前浏览器可恢复已保存的模型配置。

## 本地部署验收

- 网页版本与已加载的 EasyMultiProfiler R 包均为 9.4.0。重启前后，原有 32 个项目与会话文件的 SHA-256 校验值一致。
- 8080 网页自动恢复 MiniMax-M3.1-Flash 配置。用固定测试题调用真实服务，对话及流程工具两项均通过。插件发现接口返回 v1 清单和 Groq 示例。
- 通过 8080 上传 401 个特征、6 个样本的合成原始计数矩阵，交给当前 R 服务执行。4.78 秒完成，返回 QC、标准化、PCA、热图及 400 个特征的差异结果。重复提交返回相同作业 ID。
- Node 全量 146 项通过。Python 295 项中 294 项通过，1 项因缺少可选 GEO 公开数据夹具而跳过。ChIP-seq 的原始 reads 到峰调用仍需额外工具及单独验收。
