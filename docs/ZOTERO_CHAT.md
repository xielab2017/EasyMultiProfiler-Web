# 在 EMP 使用 Zotero 模型配置与笔记

EMP 的「模型与 API」可以导入 LLM for Zotero 的模型配置。右侧对话使用 EMP 的分析工作台、已选附件和后台任务。这个 Web 实现参照了上游的模型组、普通聊天、Agent 和 Markdown 笔记工作方式。对照版本为 [LLM for Zotero 40e58cb](https://github.com/yilewang/llm-for-zotero/tree/40e58cbda7778c3c1091e087aa966b1fbaca56a3)。上游的 Zotero 阅读器、文库、PDF 批注跳转和 WebChat 登录依赖桌面宿主。

EMP 10.3 起，先在「插件」安装并启用「Zotero 风格研究助手」，然后点击「打开聊天」。可在插件设置中选择初始展开状态。已有模型配置和当前浏览器的对话历史可继续使用。

## 模型配置

在「模型与 API → 模型配置方案」选择配置文件，可以导入上游 `modelProviderGroups` 的 JSON 值。可在 Zotero 的高级设置编辑器中检索这个名称，复制该偏好值并保存成 UTF-8 JSON。EMP 支持数组，以及包含该字段的 JSON 对象。文件可能含明文 API 密钥，请在本机处理。

导入时默认跳过密钥。EMP 会显示跳过的模型或参数；同一个来源再次导入时保留已存的配置。配置保存在当前浏览器中。选择方案并加载后，右侧对话框可以切换模型。可为同一个模型保存不同的输出额度和支持的采样参数。MiniMax 支持输出额度，其 temperature 使用服务端默认值。具体字段见[上游模型配置定义](https://github.com/yilewang/llm-for-zotero/blob/40e58cbda7778c3c1091e087aa966b1fbaca56a3/src/utils/modelProviders.ts)。

## 论文问答与分析

1. 在右侧对话选择「问答」或「Agent」。问答使用当前页面摘要和手动选择的资料。Agent 可以调用当前页面允许的 EMP 工具，适用的数据类型、样本关系和任务授权仍由工作台检查。
2. 输出类型包括回答、摘要、比较表、研究笔记、要点、研究方法、局限性和流程图。比较论文时，可用「文档」同时选中两份 PDF 或 Markdown，明确要比较的方法、样本和结果。
3. 从 Zotero 导出的 Markdown 笔记或复制为 Markdown 的对话，可保存为 `.md` 文件后加入 EMP。也可以加入 UTF-8 TXT。文本附件上限为 1 MiB，每份送入模型的节选最多 24,000 字符，同轮文档合计最多 48,000 字符。附件跨手动追问保留，点击移除即可停止在下轮使用。
4. 回答下方的「保存 Markdown 笔记」导出单条原文。「对话历史」支持新建、切换、刷新恢复和整段 Markdown 导出。对话文本保存在当前浏览器；恢复的历史只包含文字，继续阅读原文时需要重新添加附件。恢复过程不会重新执行以前的分析操作。

若输出控件显示「需更新服务」，网页当前连接的是旧版 Python AI 服务。重启该服务并重新加载模型后可使用新版输出和文档接口。

### 从 EMP 选论文

右侧「找论文」打开检索页。输入 PMID、DOI、题目，或点「试读 DESeq2 论文」。读取一条 PubMed 记录后，可以把摘要加入对话。有 PMC 编号时，可打开全文链接，或把可获取的正文作为文本附件加入对话。长文按章节分配节选额度，文件名含 `-excerpts`，正文中的 `[…]` 表示省略。扫描页、图像和补充文件需另行提供。已在检索页上传的 PDF 也能直接加入对话。

输入框上方的「摘要」「要点」「研究方法」「局限性」「流程图」用于选择当前回复的组织方式。选好后可补充自己的问题，再点发送。流程图展示资料支持的步骤。工具进度默认折叠，可以展开查看已调用的工具与耗时。「模型参数」中可调整受支持模型的思考深度。
