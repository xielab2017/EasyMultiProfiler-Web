# EasyMultiProfiler Web 10.1.0

## 插件安装与设置

点击网页顶栏的「插件管理」，可安装示例或选择第三方分析、展示插件的 `plugin.json`。安装后，在插件名称右侧点击「设置」。可在启用前完成配置。

- 分析插件可选择下一次运行要计算的指标。任务记录会保存提交时的指标选择。
- 展示插件可选择表格或条形图，设置最多显示 1–200 行。保存后再次点击「展示结果」即可使用新设置。
- 「恢复默认设置」恢复该清单中的默认值。设置按用户和清单指纹保存。更新清单后采用新版默认设置。

插件管理面板的「AI 模型插件设置」可进入「模型与 API」，配置 MiniMax 等模型提供方的连接。[插件接口与示例](../plugins/README.md)
