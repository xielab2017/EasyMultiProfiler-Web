# EasyMultiProfiler Web 10.9.0

## 按图型独立配置

普通热图、DEG 热图、火山图、箱线图、柱状图、排序图、富集、GSEA、三元图、差异显著性图、多样性和组成图新增独立的推荐尺寸、宽高、字号及标签密度设置。每种图型分别保存在浏览器，默认 10 pt、最低 8 pt。每种图都可单独选择 210 × 297 mm 的 A4 整页，导出一张纸一张图。[全部默认标准](FIGURE_STANDARDS.md)。

旧英寸输入与新毫米画布不再同时生效。旧统一配置保留为可选临时覆盖，迁移后默认关闭。前端按实际图型传入毫米尺寸；后台校验每图配置，一键导出按图型选择尺寸，并继续保留提交时的设置。

## 任务对话入口

助手增加「自动跟随页面 / 分析任务 / 文献阅读」用途切换。任务场景显示检查当前步骤、执行当前步骤、调整出图、解释结果、任务状态等快捷问题；这些按钮仅准备草稿，不直接执行。问答与 Agent 的差异始终可见，答复格式与执行模式分开说明。

Agent 白名单接入 A4 及图型设置、DEG 宽高和正确的火山图标注字段。复选框按布尔值处理，填写参数按依赖顺序触发原有事件，不能触碰密码、审核框或不属于当前步骤的控件。明确的 DEG 热图请求可以定向提交 DEG 按钮，避免落入普通热图。统一 A4 启用时，旧热图尺寸工具会提示使用实际生效的统一字段。

问答模式可解释安全的出图尺寸和字号摘要，仍不获得执行工具，也不自动发送原始矩阵或样本表。「当前页面如何出图」等说明性问题即使保留 Agent 偏好，本轮仍只解答。重复导航到当前页或重复填写已一致参数时停止无进展衔接，避免持续显示「正在衔接页面操作」而没有实际动作。

验收包括：Node 行为与字段权限测试；真实浏览器经隔离 R 服务导出独立的 180 × 220 mm DEG 热图、110 × 90 mm 火山图，以及按图型选择的 210 × 297 mm A4 热图。直接解析 PDF 单页、物理尺寸、有效字号和标签间距；验证独立修改、刷新恢复、全局覆盖及中英文/窄屏。后台按图型导出和配置恢复另有 R 测试。本次未用真实 MiniMax 对话执行完整科研任务，不能据此宣称模型在所有分析场景均已验收。

本机升级；源码及已部署版本需分别核对。原有历史图需要重新生成，第三方专用图形仍未全部验收。
