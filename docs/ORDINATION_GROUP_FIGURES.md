# 降维分组椭圆与轴向投影统计

「分析 → 降维」选择已保存结果，再选择「样本分组」。默认绘制 95% 正态组内分布椭圆，半透明填充在散点后方，白色点边框帮助区分重叠点；坐标保持二维原值，不生成虚构的第三维。主图上方显示 X 轴分组箱线图与样本点，右侧显示 Y 轴分组箱线图与样本点。图例包含各组样本数，缺失分组点统一为灰色，并先绘制在背景中，已知分组点绘于其上，坐标不变。

可调整或关闭椭圆，修改置信 / 覆盖水平和填充透明度，关闭轴投影，选择秩检验、Welch 或不检验。均值置信区域保留为明确命名的可选项，旧默认配置首次更新为分布椭圆，之后保留用户的明确选择。「本图独立设置 → 文字、线条、配色与导出」可选配色方案、自定义组颜色（按图例组别顺序）、字号、线宽、点径、图例位置及物理尺寸；其他图型设置不受影响。新增选项在本浏览器保存。需要更多排版空间时可自行选择 180 × 160 mm；系统不强制修改已选尺寸或字号。

## 椭圆的含义

- **组均值置信椭圆**：在独立、二维正态样本的假定下，对该组总体均值的位置给出 Hotelling 置信区域。若组内样本数为 n、样本协方差为 S，边界满足 `(mu - mean)' S^-1 (mu - mean) = 2(n-1)/(n(n-2)) F(level; 2, n-2)`。这是每组的置信水平，没有针对多个组做联合覆盖校正。
- **样本分布椭圆**：正态模型下以样本均值为中心、协方差 S 和 `chi-square(level, 2)` 形成的分布范围展示；不是均值置信区间，也不保证有限样本的精确覆盖。
- 两种椭圆都要求至少 3 个非共线的已知组样本。样本不足或协方差奇异时保留点并说明跳过原因，不补造椭圆。很小样本的均值置信区域可能很大，可查看样本量并按目的选择分布展示。

## P 值与统计边界

每条轴默认比较有重复样本的已知组（n≥2）的投影分布。没有重复的组仍保留在散点、图例和箱线投影中，检验标题、页面和审计记录说明排除组与样本数；可选「全部组」，不足时返回 NA 而不偷偷排除。默认两组采用双侧 Wilcoxon 秩和检验（正态近似、连续性校正），三组及以上采用 Kruskal–Wallis；Welch 选项分别采用不等方差 t 检验或不等方差单因素检验。至少需要两个组、每组至少两个有效样本；常量、不可估计结果或用户关闭检验时报告 NA 和原因。

每个轴向投影的标题直接显示该轴总体组间 P 和 BH q；BH 的比较族仅包括当前选择的两条轴。总体检验与两两比较分别记录。默认计算全部纳入组对，也可选择参考组或关闭两两比较。每对使用双侧 Wilcoxon 或 Welch t 检验，BH 在本次请求的所有组对与两条轴组成的比较族内校正。缺失、NaN 和空白分组只在散点图中保留，不参与椭圆、边际分布或轴检验，也不作为一个真实组进行检验。

这些检验假定样本独立。配对、重复测量或批次设计未纳入该轴向检验。PCA / PCoA / UMAP / t-SNE 坐标来自数据与所选算法，轴向 P 值属于探索性描述，尤其非线性嵌入的坐标差异不能作为原始空间组间差异的确认性检验。没有计算或冒充原始距离矩阵上的 PERMANOVA。

重画不重新拟合降维模型；椭圆和轴向统计根据保存的坐标与该结果保留的分组元数据计算。完整投影数据下载为 DATA，原始 P、BH q、检验名称、统计量、有效 N、缺失 N、各组数量和不可估计原因下载为 STATS。MANIFEST 同时记录参数、颜色、各组椭圆状态、统计结果与源文件校验值。

PNG / PDF / SVG 包含同一组合图；PDF / SVG 保留矢量对象，物理宽高沿用本图设置。旧结果未保留分组时，只能先显示未分组散点；不会偷换成当前数据的分组。

## 两两比较标注与下载

投影图用括号标注组对，默认显示原始 P，也可改成 BH 校正 P 或两者。最多标注组对数由用户选择（默认每轴 6 项）；完整统计不会按显示数量截断。总体检验 BH 的比较族是两条轴；两两比较 BH 的比较族是所有请求组对 × 两条轴，两者不能混用。

画布相对文字过紧时，不把括号 P 值裁掉：保持分布和总体 P 完整，将两两比较显示在默认展开的统计表与 PAIRWISE 下载中，并给出提示；可自行增大画布或减小标注字号以显示括号。软件不强制修改尺寸和字号。图例、标题和分布仍在原物理画布内。

PAIRWISE CSV 和 MANIFEST 保留每条轴、每个组对、检验方法、原始 P、校正 P、N1/N2、无法估计原因及显示数量。统计表默认展开；可查看未纳入推断的单例组及实际检验样本数。两两检验同样仅用于独立样本的探索性比较。

参考：[R 两两 Wilcoxon 检验](https://stat.ethz.ch/R-manual/R-patched/library/stats/html/pairwise.wilcox.test.html)。
