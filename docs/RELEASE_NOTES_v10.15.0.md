# EasyMultiProfiler Web 10.15.0

降维、相关、聚类、标志物分析页集成按方法保存结果与直接出图，无需跳转寻找图形入口。

- 覆盖页面上的 16 个方法分支：PCA / PCoA / UMAP / t-SNE / MDS，三种相关系数，三种聚类，以及 RF / LEfSe 备用 / ANCOM 备用 / LASSO / XGBoost。
- 运行完成后保存独立结果并自动出图；可回看同一方法的不同历史结果。重画仅读取结果，不重新拟合；后台运行也保存结果与关联任务。
- 降维散点、相关热图与网络、聚类树 / 投影 / 归属 / 数量、标志物分数条形图，分别提供本图尺寸与外观设置、PNG / 矢量 PDF / SVG、本图 CSV 和来源清单。
- 修复 t-SNE 错误映射到 UMAP，采用真实 Rtsne；UMAP 使用 R 实现。依赖缺失明确报错。旧错标任务按保存的 UMAP 列说明实际方法。
- LASSO 保留有方向的系数；XGBoost 保留 Gain；LEfSe / ANCOM 继续明确标注 RF 备用，不生成不存在的 LDA、W 或验证 ROC。
- 旧任务可从保存表出图；缺失聚类树、投影或分组元数据不会隐式重算或以当前数据替代。

用法、方法对应图型、依赖与接口见 [集成出图说明](ANALYSIS_RESULT_FIGURES.md)。

验收：176 项 Node 测试；16 个方法的真实 R 计算、结果冻结与绘图；真实浏览器逐项切换方法出图，验证后台运行完成自动出图、单独修改尺寸、不重跑分析和窄屏展示；四类 PDF 页面物理尺寸正确且无栅格图像对象。附加验证覆盖历史错标 t-SNE、旧聚类缺树保护、所有权和实验隔离。每份绘图清单带源文件校验值及原始分析参数。
