# EasyMultiProfiler Web 10.12.0

新增每图独立的「自动参数配置」复选框，替代原先的自动按钮与排版模式选择。

- 勾选：用户指定画布宽高和单位，系统按物理尺寸计算基准字号、各类文字、线宽、图例、配色和分辨率，并结合观察值数量计算点径及标注密度。参数面板只读并显示实际采用值；火山图标注数也自动控制。
- 勾选或修改尺寸后，自动生成当前图型；连续修改宽高会合并为一次生成，已有任务运行时等候完成。手动点击生成会取消同一图型的待触发自动任务，避免重复提交。
- 取消勾选：恢复之前的手动参数，用户可自由编辑再点击生成。自动与手动配置分别保留，按图型存储，刷新后不丢失。未选择实验时先保留配置。
- 图宽高、数据分组、统计阈值及分析条件仍由用户指定，自动设置只控制绘图外观。
- 后端重新计算自动配置，忽略自动模式中的旧手动覆盖；后台绘图同样携带各图型自动配置。大画布按位图像素容量自动选择 DPI。
- 自动热图按大小调整树高、格线与标签间隔，小画布将连续色阶及分组图例放到底部并预留文字空间；矩阵数据和聚类输入保留。
- 火山图继续使用 NS 灰、Up 红、Down 蓝，图例纵向 NS → Up → Down；基因名称仍在点云两侧并连回真实坐标。

验收：169 项 Node 测试通过；浏览器检查自动开关、600 ms 合并生成、尺寸变化后的字体与线宽重算、手动参数恢复、刷新、分图型隔离、中英文与窄屏。R 检查 60 / 87 / 120 / 180 mm 自动热图均保留 200 行输入，检查字体及 DPI 后端计算、旧手动出图、后台任务与富集图导出。实际 PDF 验证物理尺寸、字体、完整图例及 NS / Up / Down 的纵向顺序。
