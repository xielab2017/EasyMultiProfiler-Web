# EasyMultiProfiler Web 10.0.0

本地合并版本，由 9.4.0 升级。RNA-seq 分析可靠性、可复用流程与第三方插件接口在同一版本交付。

## RNA-seq 从提问到结果

在「AI 分析工作台」展开「用自然语言生成 RNA-seq 计划」。可以输入「比较处理组和对照组，看看哪些基因上调」，也可以指定「DESeq2 差异分析，FDR 1%，绘制前 20 个基因的热图」。工作台给出可编辑的步骤，并提示补齐计数来源、样本对应关系、参考组和独立样本设计。当前本地指令解析使用已注册的方法和参数。外部模型可通过 Agent 工具提出流程草稿。

审核后运行。每个差异结果显示比较方向、组别样本数、检验数、显著数和阈值，可下载该比较的完整 TSV。反转比较时正负方向随之改变。窄屏上的 AI 助手和任务托盘可按需打开。

「导出 RNA-seq 参数模板」保存方法、步骤、参数和随机种子。「套用 RNA-seq 参数模板」可将其应用到另一份计数矩阵。新数据的分组、证据和比较方向需要审核。用已完成的任务 ID 可重新查看结果及其数据来源、参数、软件版本。较早任务缺少的字段显示为「该任务未记录」。

## 第三方插件

模型服务使用已有的提供方插件接口。在工作台的「分析与展示插件」中，可以安装内置示例或开发者提供的 `plugin.json`，核对其申请权限后启用。分析插件对当前会话已导入实验的 assay 计算按样本或特征的统计量，生成带版本及摘要标识的后台任务结果。展示插件读取这种结果，绘制表格或条形图。新版本的插件需重新启用。

首次体验可在导入页添加实验矩阵，安装并启用 `sample-quality` 和 `quality-bars`，选择实验、运行分析，再选择对应任务和展示插件。第三方开发者可参考[开发与权限说明](../plugins/README.md)、[分析示例](../plugins/examples/sample-quality/plugin.json)、[展示示例](../plugins/examples/quality-bars/plugin.json)和[模型提供方契约](../plugins/ai-providers/README.md)。
