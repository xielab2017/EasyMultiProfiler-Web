# EasyMultiProfiler Web 10.7.0

可视化页新增「投稿画布尺寸 · PDF / Illustrator」，可统一指定画布宽度、高度和单位（mm / cm / inch）。切换单位保持实际尺寸不变。启用时，物理画布宽高优先于单图宽高和全局尺寸缩放；字号仍按原有 pt 与字体缩放规则处理。关闭后恢复各图的尺寸设置。修改后需重新生成图形，已有 PDF 不会被事后缩放。

火山图新增独立宽高，默认 8 × 7 英寸。DEG 热图继续使用独立宽高。热图格子根据画布布局，避免固定单元格大小导致超出指定页面。

下载 PDF 后在 Illustrator 中以 100% 放置。宽高指包含标题、坐标轴、图例和留白的整个 PDF 页面。PDF 保留图形及文字的矢量输出；DPI 不影响其页面尺寸。富集图和方法库图使用同一 PDF 设备路径，本机 Quartz 保留毫米换算的分数点。其他系统的基础 R PDF 设备可能按整数点取整（小于 0.353 mm）；跨平台精度应按实际 PDF 页面检查。

位图可选择 72 / 150 / 300 / 600 DPI。PNG 显式记录物理分辨率；JPEG 保留 JFIF DPI；TIFF 使用真实 RGB TIFF 格式并写入分辨率标签。位图尺寸会有至多一个像素的取整偏差。为控制浏览器内存占用，统一画布每边为 10–914.4 mm，位图最多 4000 万像素；前后端均校验。

统一设置适用于可视化页中通过当前绘图接口重新生成的图，包括箱线、柱、热图、火山、散点/排序、组成、多样性、16S、富集、GSEA 和方法库图。临床页、ChIP 专用页、后台分析任务生成的历史图片和第三方插件自带输出不在此次统一设置范围内。
