# EasyMultiProfiler Web 10.5.1

- 插件商店按可用宽度排列卡片，在窄窗口和打开聊天侧栏时自动换行。每张卡片显示插件类型、版本和状态，常用操作与权限详情分区。
- 插件管理页使用统一的刷新入口。插件分析和结果展示各有独立的表单区域。
- 插件设置弹窗更新标题、字段和按钮布局，并为保存与恢复默认设置保留独立操作。

## 主分支发布

本版将 9.4 至 10.5 的工作台和插件改进纳入主分支，包含 RNA-seq 方案审核与后台运行、Zotero 风格研究助手、Groq 模型接口、插件安装和设置，以及中英文预览。

前端、API、项目快照和可复现报告从同一版本源读取版本信息。安装入口及源码下载见[英文 README](../README.md)和[中文 README](../README_CN.md)。
