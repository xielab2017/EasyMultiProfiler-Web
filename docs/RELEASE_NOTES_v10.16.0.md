# EasyMultiProfiler Web 10.16.0

降维结果图新增分组椭圆、分层配色、两条坐标轴的边际投影与探索性统计，不重新拟合保存的 PCA / PCoA / UMAP / t-SNE / MDS 坐标。

- 可选组均值置信椭圆、正态分布椭圆或关闭，默认 95%，可调整覆盖水平和透明度。半透明区域位于点后方，点加白色边框；图例包含各组数量，缺失分组统一为灰色。
- 上方和右侧分别提供 X / Y 轴分组箱线图与样本点，沿用主图坐标范围。默认 Wilcoxon / Kruskal–Wallis，可改 Welch 或关闭；显示原始 P 与仅针对当前两轴的 BH q。
- 至少三个非共线样本才能估计椭圆；轴检验要求至少两个已知组、每组至少两个样本。缺失 / 空白 / NaN 分组不进入检验；不可估计结果说明原因，不生成假 P 值或补造椭圆。
- 新增 STATS 下载，保留检验、统计量、P、BH q、有效和缺失样本数、分组数量及原因。MANIFEST 记录椭圆状态、颜色、统计与源校验值。PDF / SVG 仍为指定物理尺寸的矢量组合图。
- 参数按浏览器保存；配色、字体、线宽、点径及图例位置仍由本图设置管理。修复合成图自动样式造成的重复图例，保留用户选择的图例位置。

统计定义、假定、使用方法与主要参考见 [降维图说明](ORDINATION_GROUP_FIGURES.md)。轴向检验为独立样本的探索性比较，不替代配对 / 重复测量模型或原始距离矩阵上的 PERMANOVA。

验收：176 项 Node 测试；R 核对轴向 P / BH、Welch / Kruskal–Wallis、Hotelling 几何边界、分布椭圆、缺失 / 单例 / 奇异协方差及坐标不变；真实浏览器验证分组椭圆、两轴统计、配色、各项切换、自动 / 手动设置、参数保存和窄屏。导出 PDF 物理尺寸正确，无栅格图像对象，只有一份组别图例；DATA 保持保存坐标，STATS 与清单完整。
