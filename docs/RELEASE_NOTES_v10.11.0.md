# EasyMultiProfiler Web 10.11.0

- 图型独立设置：移除可视化页的全局样式和统一 A4 配置区；各图型分别保存尺寸、单位、字号、配色和导出分辨率。
- 字号接受任意有限正数和小数，不再限制为 8–24 pt；保留可见的 − / + 半点步进按钮。手动模式不联动更改其他字号，最小字号策略仅在自动或严格排版时生效。默认 10 / 8 pt 仅为起始值。
- 新增标题、坐标刻度、坐标标题、图例和数据标注的独立字号，以及字体选择。留空继承基准字号或原图默认值。
- 按图型配置线宽：坐标轴与外框、图形曲线与边线、阈值参考线、网格；热图单独设置单元格边框和聚类树。线宽使用 pt；点大小使用 mm，保留已有按数据映射的气泡大小。
- 配色方案、自定义颜色、图例位置、背景和绘图方法分别随图型保存。PDF 仍使用实际物理尺寸和可编辑矢量文本；修改后需重新生成旧图。
- 默认手动模式按用户尺寸和字号出图：不再用 A4、40–297 mm、文字密度或图体空间阈值阻止绘图；不自动放大字体、不抽取标签、不改变画布。
- 每张图新增「自动配置此图」按钮：用户主动选择后应用该图型推荐尺寸和默认字号，并启用标签自动间隔；可随时切回手动。
- 尺寸单位仍支持 cm / mm / inch / point。参数要求有限正数，位图保留 4000 万像素资源上限。

Validation / 验收：167 项 Node 测试通过；R 检查覆盖字号、线宽、不可变绘图对象、后台任务及手动出图。隔离服务与已部署 8080 页面均实际下载 PDF 并解析：4 / 7.25 / 28 pt、单元格边线 0.5 pt、聚类树 2 pt；用户同款 76.2 × 101.6 mm / 7 pt 手动配置成功输出，200 个标签全部保留。自动配置按钮、跨图独立保存、刷新持久化、中英文和窄屏也通过浏览器检查。源码、网页和 R 实际加载包版本均为 10.11.0；MiniMax 会话保留。
