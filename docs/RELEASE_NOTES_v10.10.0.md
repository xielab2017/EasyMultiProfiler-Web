# EasyMultiProfiler Web 10.10.0

每个「本图独立标准」增加 cm / mm / inch / point（pt）单位选择。宽高按所选单位显示、编辑和保存；字号仍使用 pt。切换单位保持物理尺寸，不改变推荐 / 自定义方案。推荐与 A4 整页尺寸在当前单位下换算显示；临时全局覆盖也支持 point 并保留所选单位。

使用 PDF / Illustrator 定义：1 inch = 25.4 mm = 72 point。前端在发送绘图请求前统一换算为毫米，后端使用原有毫米契约，避免单位混用。A4 边界按换算后的毫米校验，缓解浮点误差导致整页预设误报越界。旧配置没有单位时按毫米读取。

单位设置跟随各自图型保存；修改 DEG 热图的单位不改变火山图。AI 页面操作白名单增加单位字段，组合填写时先切单位再应用目标宽高，并按目标单位的物理范围预校验。即使显示数字相同，切换单位后的明确宽高输入也会重新应用。

验收：165 项 Node 测试通过，包括四单位换算、循环切换精度、旧配置兼容和字段填写顺序。真实浏览器连接隔离 R 服务，核对毫米、厘米、英寸和 point 的同尺寸请求；核对刷新后单位与尺寸保持。实际下载 PDF 的 360 × 432 point 成图为 127 × 152.4 mm，point 单位下的 A4 预设为 210 × 297 mm；保留现有物理画布、字号下限、独立图型及中英文/窄屏检查。

本版为本机升级。发布后核对网页 /version.json 与 R /api/health 实际加载版本；MiniMax / Python 模型服务可继续保留。
