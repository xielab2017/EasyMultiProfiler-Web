# EasyMultiProfiler Web 10.8.0

A4 投稿排版与可读性升级。按 Illustrator 的 pt 单位配置文字，默认基准 10 pt，最小字号默认为 8 pt，可将最小字号提高到 10 pt。所有新增设置保持现有 API 的兼容性。

- A4 纵向整页 210 × 297 mm、横向整页 297 × 210 mm，以及通栏图块 180 × 120 mm、双列图块 87 × 87 mm、三列图块 56 × 56 mm。图块参考 15 mm 页边距与 6 mm 栏间距；每张 PDF 是一个图块，供 Illustrator 以 100% 放置。预览不代表自动将多张结果拼成一页。
- 单位支持 mm / cm / inch，切换时保持实际尺寸。自定义可保留 2.1111 × 2.1111 英寸等 Illustrator 图块尺寸。设置保存在当前浏览器，刷新后恢复。物理尺寸可统一设置，也可关闭后使用各图独立尺寸；投稿字号规则仍然应用。
- 投稿基准字号控制坐标轴、标题、图例、分面与文字标注；最小字号不能低于 8 pt。数学上下标会补偿缩小比例，最终 PDF 内的有效文字尺寸也需满足最小字号。画布缩放不会将这些文字缩小到下限以下。过小的画布会给出扩大图块的提示。
- 热图保持所有矩阵值、聚类与数据顺序。自动模式按最终聚类后的顺序间隔显示标签，并报告显示数量；严格模式要求全部标签，过密时停止并提示。临床热图单元格标注随标签一起间隔，完整统计表保留。无法放下图例和标签时拒绝生成拥挤输出；不会通过降低字号或移除聚类规避版面检查。
- 共用规则接入原生可视化、临床绘图、16S / ChIP 共用绘图路径、富集与 GSEA、方法库及一键分析导出。请求中的投稿设置会传入隔离后台任务并在结果中记录。PNG / PDF / SVG 的共用导出采用同一物理尺寸与字体策略；局部渲染随机种子保证重复绘图的稳定性，不改变统计计算的随机状态。
- AI 计数工作台的 PCA 和热图新增投稿 PDF / SVG 导出，读取已完成任务的冻结坐标或矩阵，不重新运行分析；导出绑定所展示结果的任务 ID 并检查所有权。图形工具栏可直接打开 A4 设置。

验收：浏览器连接隔离 R 服务，检查 87 × 87 mm 火山图、180 × 120 mm 的 200 基因热图与 210 × 297 mm 的 A4 整页箱线图。直接解析下载 PDF 的页面尺寸、单页内容与最终变换后的有效文字大小（包含数学上下标），确认均不低于 8 pt，并核对热图标注间距。检查过小画布拒绝、严格标签模式、8 pt 字号下限、刷新恢复、中英文与 320 / 768 / 1024 / 1440 px 布局。原有 Node 测试和新增投稿排版测试通过；R 测试覆盖字体、聚类不变、后台任务配置传递、冻结工作台导出及现有导出 / 富集 / 一键分析。

现有历史图片需要重新生成。第三方工具自身生成的位图、外部程序的专用图形与任意第三方插件不能通过改画布变成可编辑矢量；这些产出仍需要对应工具或插件提供原生矢量导出并遵守投稿配置。本机未配置外部方法库，外部库与 DiffBind / deepTools 专用运行路径未完成实际数据集成验收，不应据此宣称所有外部图形均已验证。

本版为本机升级；部署时需安装对应 R 包，核对网页 /version.json 和 R /api/health 的实际加载版本。GitHub 已发布版本与本机源码版本分别标注。
