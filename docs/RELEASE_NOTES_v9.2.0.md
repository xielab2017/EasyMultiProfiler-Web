# EasyMultiProfiler Web v9.2.0

This version brings together the local matrix discovery and download interface, paper and PDF source discovery, an AI-guided workflow editor, multi-study project management, and model API settings. The workflow editor distinguishes executable analyses from planning-only steps; review data types, sample metadata, contrasts and parameters before running an analysis.

Paper accessions are unverified candidates. GEO provides a managed processed-data download flow; PRIDE offers a bounded search for candidate public tables and links to the official server. Other repositories, including China's NMDC, currently require users to inspect and download files on the repository website. A repository accession alone does not establish that a file is a suitable analysis matrix. The AI guide uses selected public context and requires model configuration and user consent.

Availability and compatibility vary by analysis type. Full cross-platform installation, all provider connections, and all possible multi-omics workflows have not been verified for this release. Refer to the workbench and repository documentation for supported operations and limits.
