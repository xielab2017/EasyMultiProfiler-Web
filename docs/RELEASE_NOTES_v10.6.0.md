# EasyMultiProfiler Web 10.6.0

DEG 热图区域新增独立的「图片宽度（英寸）」和「图片高度（英寸）」设置，默认 11 × 8。宽度范围 4–30 英寸，高度范围 4–36 英寸，可分别调整。生成热图时使用这两个值，图片预览和 PDF 导出均采用对应画布尺寸。全局图片缩放系数继续参与尺寸计算。

普通热图与自定义列表热图使用上方的尺寸设置。DEG 的两个输入框可分别修改宽度与高度。

验收使用独立实例和合成矩阵，分别生成 6 × 5、8 × 5、8 × 7 英寸的热图，核对 300 DPI PNG 的实际像素尺寸和 PDF 画布尺寸。已检查空值与范围校验、中英文标签和窄屏显示。
