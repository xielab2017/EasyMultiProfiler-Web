# Zotero-style research chat

[中文](README.md)

Read papers alongside your analysis. Use an existing MiniMax or other model connection to turn a question into a research note.

![Illustration of a methods question and a research note.](https://xielab2017.github.io/EasyMultiProfiler-Web-Plugins/assets/previews/zotero-style-chat-en.svg)

[Install in EMP](http://127.0.0.1:8080/#plugins/zotero-style-chat) · [Plugin page](https://xielab2017.github.io/EasyMultiProfiler-Web-Plugins/en/examples/zotero-style-chat/)

EMP 10.3.0+ · v1.0.0

Online installation requires EMP 10.4 or later. The install button opens port 8080 on this computer. For another address, open Plugins in that EMP instance.

1. In EMP 10.4 or later, open Plugins and select Install and enable on the research chat card.
2. Load a model under Models and API, then select Open chat on the plugin card.
3. Attach a PDF, abstract or Markdown note. Select Key points, Methodology or Limitations and send your question.

Choose a collapsed, expanded or screen-adaptive panel in Settings. Chat and Agent share the EMP model connection. Saved conversations remain in this browser after disabling the plugin. A running Python AI service and a configured model are required.

chat.panel opens the research chat panel provided by EMP.
