# Zotero 风格研究助手

[English](README.en.md)

在分析页面边读论文边提问，用已有的 MiniMax 或其他模型整理研究笔记。

![研究对话示意，展示方法提问与研究笔记。](https://xielab2017.github.io/EasyMultiProfiler-Web-Plugins/assets/previews/zotero-style-chat-zh.svg)

[在 EMP 中安装](http://127.0.0.1:8080/#plugins/zotero-style-chat) · [插件页面](https://xielab2017.github.io/EasyMultiProfiler-Web-Plugins/examples/zotero-style-chat/)

EMP 10.3.0+ · v1.0.0

在线安装需要 EMP 10.4 或更高版本。安装按钮打开本机 8080 端口。使用其他地址时，直接从该实例的「插件」页安装。

1. 在 EMP 10.4 或更高版本，打开「插件」，点击研究助手卡片的「安装并启用」。
2. 在「模型与 API」加载已有的模型，然后在「插件」的已安装列表点击「打开聊天」。
3. 在对话框加入 PDF、摘要或 Markdown，选择「要点」「研究方法」或「局限性」后发送。

设置可选择随屏幕大小、展开或收起。问答与 Agent 共用 EMP 的模型连接。启停保留当前浏览器保存的对话文字。需要 EMP 的 Python AI 服务和可用模型。

chat.panel，使用 EMP 提供的研究对话窗口。
